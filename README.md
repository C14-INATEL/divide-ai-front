# Divide AI Front

Frontend do projeto **Divide AI**, desenvolvido com **React + Vite**.

## 🚀 Como rodar o projeto

### 1. Clonar o repositório

```bash
git clone https://github.com/C14-INATEL/divide-ai-front
```

### 2. Entrar na pasta do projeto
```bash
cd divide-ai-front
```

### 3. Instalar as dependências
```bash
npm install
```

### 4. Rodar o servidor de desenvolvimento
```bash
npm run dev
```

Após executar o comando, o projeto estará disponível no endereço mostrado no terminal (normalmente http://localhost:5173).
